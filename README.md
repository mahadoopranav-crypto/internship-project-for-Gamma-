# Task 1: Shopping Malls and Supermarkets in Mauritius
## Columns

| Column | Description |
|---|---|
| Name | Supermarket brand or mall name |
| Type | Supermarket or Shopping mall |
| Address | Street address |
| Town | Town or locality |
| District | District of Mauritius |
| Phone | Public phone number, where available |

## Sources

- OpenStreetMap, for supermarkets and malls by district
- Nominatim reverse geocoding, for street names missing from OpenStreetMap
- winners.mu store pages, for Winners branch addresses and phone numbers
- dreamprice.mu store page, for Dream Price branch addresses and phone numbers
- Google Maps to double check the adresses and phone numbers

## Notes

- The list covers places within about 60 supermarket and 26 shopping malls 
- Supermarkets are grouped by brand (Winners, Dream Price, Intermart, Carrefour), followed by independent stores.
- Only public business information was collected. Blank cells mean no source published that detail.
